# Campaign Detection & Infrastructure Clustering

## Correlation Dimensions
MailTracer.ai correlates attacks across 5 distinct dimensions:
1. **Identical or Near-Identical Threat DNA**: Cases sharing matching sub-fingerprints.
2. **Shared Autonomous Systems (ASN)**: Traffic routing through identical bulletproof hosting providers.
3. **Identical Attachment Hashes**: Distinct emails distributing the exact same dropper binary or weaponized workbook.
4. **Targeted Brand Stems**: Coordinated typosquatting campaigns mimicking the same enterprise brand.
5. **Diverted Reply-To Infrastructure**: Disparate sender addresses diverting responses to the same adversary-controlled webmail relay.
